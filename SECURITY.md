# Security Policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in public GitHub issues. Report them privately to the repository maintainers with the affected component, impact, reproduction steps, and any relevant logs that do not contain secrets or personal data.

## Security baseline

AI Core follows a defense-in-depth model covering authentication, tenant isolation, least privilege, auditability, idempotency, human approval for sensitive writes, dependency hygiene, CI verification, and secure software supply-chain practices.
